1. Cabinet pakai IR

Pedal Effects
      ↓
    AMP
      ↓
  CAB IR
      ↓
   OUTPUT

Cabinet pada dasarnya melakukan convolution antara sinyal gitar dengan file impulse response.

Misalnya:

input audio
    ↓
Amplifier
    ↓
Convolution
    ↓
"4x12 Marshall-style IR"
    ↓
output

Kamu bisa menyediakan beberapa cabinet:

1×8
1×10
1×12
2×12
4×10
4×12
Open Back
Closed Back

Dan masing-masing bisa punya beberapa karakter mic:

SM57
Sennheiser-style
Ribbon
Condenser

Bahkan UI-nya bisa seperti:

┌──────────────────────────┐
│       CABINET            │
│                          │
│  Cabinet: [ 4x12 ▼ ]     │
│  Mic:     [ SM57 ▼ ]     │
│                          │
│  Position: ●──────○      │
│            Edge   Center │
│                          │
│  Mix:      ███████░ 80%  │
└──────────────────────────┘
